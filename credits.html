    Other data

    • Country names and borders (for "Where am I" and for going to a place): Natural Earth, 1:50m Admin 0 Countries, version 5.1.2. Public domain. Borders are simplified to about 1 km, so distances near coasts and borders are approximate.
    • The real sea temperatures in the accuracy table on How it works: JPL MUR SST v4.1, read from NOAA CoastWatch ERDDAP (dataset jplMURSST41).

    Libraries and fonts

    None. The site uses only plain HTML, CSS and JavaScript, with the browser's built-in Web Audio, Canvas, Speech Synthesis and Speech Recognition APIs, and the device's system font.
