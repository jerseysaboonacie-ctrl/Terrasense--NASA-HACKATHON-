Decoder test

Shows how each pixel colour is turned into a value, so you can check the decoder against NASA's colourbar by eye. Values are approximate: a colour is not a measurement.

Explore

Move the pointer over the frame, or focus it and use the arrow keys (Shift + arrow moves faster). Click, or press Enter, to add the point to the check below.

Move over the frame to read a value.

Zoom: 21 by 21 pixels. The box shows the 3 by 3 square the decoder reads.

Legend

Top: the legend table the decoder uses, drawn from data/frames.json, with a marker at the last decoded value. Below: NASA's original colourbar. The two should look the same.

Ten-point check

Add the points you want to check by clicking the frame, or fill the table with ten points spread across the legend range plus two no-data examples. For each row, compare the zoomed pixel with NASA's colourbar and type the value you read by eye. Rows more than one legend step apart are flagged.
